ШАГ 2. ХОСТИНГ ДЛЯ pcm2.ru
===================================================================

2.1. Что есть сейчас
--------------------
В «Активных услугах» только «Домены» (7) и «DNS-хостинг» (1).
Хостинга для сайтов в договоре нет — заказываем новый. Услуга
«DNS-хостинг» обслуживает pc-moscow.ru, к нашей задаче не относится,
не открываем.

2.2. Заказ хостинга
-------------------
nic.ru → меню «Хостинг» → «Виртуальный хостинг» (не «Хостинг для
CMS», не «Конструктор сайтов», не VPS).

Какой тариф:
  • НЕ самый младший — он заявлен «для статичных сайтов», нам нужен
    PHP и планировщик.
  • Второй по цене тариф. В него у Руцентра входит SSL-сертификат —
    это закрывает шаг 5 без покупок и ручных обновлений.
  • Перед оплатой проверить в описании тарифа: PHP 8, планировщик
    (cron), .htaccess / mod_rewrite. Если чего-то не видно — спросить
    в чате поддержки до оплаты.

В форме заказа:
  • домен — «использовать существующий» → pcm2.ru
  • срок — на год (скидка «Хостинг до 30%» из вашего пакета действует
    на весь срок оплаты; на 3 года дешевле, но возврата денег у
    Руцентра нет — берите год)
  • SSL-сертификат в комплекте — оставить, выпускать на pcm2.ru
  • выделенный IP, почта, антивирус, конструктор, «перенос сайта» —
    снять, не нужны
  • если предложат тестовый период — брать: сайт можно поднять и
    проверить до оплаты

Оплата с баланса договора (доступно 4 390 ₽). Услуга появляется в
«Активных услугах» строкой «Хостинг» через несколько минут, на почту
приходит письмо с адресом панели и паролями. После этого в кабинете
у карточки хостинга — кнопка «Панель управления».

2.3. Добавить сайт pcm2.ru в панель
-----------------------------------
Панель хостинга → «Сайты» → «Создать сайт»:
  • имя сайта: pcm2.ru
  • «Продолжить» → вкладка «Без CMS» → «Продолжить»
Панель создаст папку сайта и покажет её путь — запишите его,
это КОРЕНЬ САЙТА (у вас: /home/pcm7937440/pcm2.ru/docs).
Если хостинг заказан сразу с доменом pcm2.ru — сайт уже создан,
просто откройте его карточку и найдите путь.

2.4. Версия PHP
---------------
Панель → «Сайты» → pcm2.ru → настройки сайта → «Версия PHP» →
выбрать 8.1, 8.2 или 8.3 → сохранить.
Настраивается ДЛЯ САЙТА pcm2.ru. Никаких общих настроек хостинга
не меняем. Минимум, на котором сайт работает, — 7.4.

2.5. FTP-доступ
---------------
Панель → «FTP и SSH» → «Создать пользователя»:
  • логин: любой латиницей, например pcm2
  • пароль: сгенерировать, сохранить в надёжном месте
  • директория: выбрать сайт pcm2.ru (пользователь увидит только
    его папку — так вы физически не сможете залить файлы куда-то ещё)
  • «Создать»
Там же панель показывает адрес FTP-сервера (вида ХХХ.nichost.ru
или IP) — он понадобится в 3.1.

ШАГ 3. ЗАЛИТЬ ФАЙЛЫ
===================================================================

3.1. Подключиться по FTP
------------------------
Программа FileZilla (бесплатно, filezilla-project.org).
Файл → Менеджер сайтов → Новый сайт:
  Протокол:      FTP
  Хост:          адрес из 2.5
  Порт:          21
  Шифрование:    «Использовать явный FTP через TLS, если доступен»
  Тип входа:     Нормальный
  Пользователь:  логин из 2.5
  Пароль:        пароль из 2.5
→ «Соединиться». Справа откроется папка сайта на хостинге.
Если внутри уже есть файл-заглушка index.html — удалить его.

FileZilla → меню «Сервер» → поставить галку «Принудительно
отображать скрытые файлы» — иначе не увидите .htaccess.

3.2. Что заливать
-----------------
Сначала — шаг 0 из первой инструкции: положить в data/ свежие json
с uitop.ru (https://uitop.ru/backup.php?key=porsche).

Затем слева в FileZilla открыть папку архива pcm2-upload и выделить
ВСЁ её содержимое (не саму папку):

  .htaccess  index.php  admin.html  robots.txt  sitemap.php
  support.js  backup.php  import-cars.php
  assets/  inc/  pages/  data/  images/  api/  tractors/
  ЧИТАТЬ-СНАЧАЛА.txt и этот файл — можно не заливать

Перетащить в правое окно, в КОРЕНЬ сайта (в папку docs, не рядом
с ней). ~110 файлов, 2–5 минут. В конце в FileZilla вкладка
«Неудавшиеся передачи» должна быть пустой.

3.3. Права на папку data/
-------------------------
В правом окне FileZilla → правой кнопкой по папке data → «Права
доступа к файлу…» → числовое значение 775 → галка «Перенаправить во
вложенные каталоги» → «Применить только к каталогам» → ОК.
Без этого админка и импорт каталога не смогут ничего сохранить.

3.4. Проверить, что .htaccess на месте
--------------------------------------
В правом окне в корне сайта должен быть виден файл .htaccess
(с точкой в начале). Если его нет — перетащить отдельно.
Без него работает только главная страница.

4.1. IP хостинга (если нужен способ через hosts)

===================================================================
ШАГ 5. HTTPS-СЕРТИФИКАТ
===================================================================
У Руцентра в панели хостинга НЕТ автоматического бесплатного
Let's Encrypt. Варианты по порядку предпочтения.

Путь А — сертификат из комплекта тарифа (в «Базовом» его НЕТ → А2 или Б)
---------------------------------------
Если при заказе (2.2) выбран тариф с SSL в комплекте — сертификат
на pcm2.ru выпускается и ставится на хостинг АВТОМАТИЧЕСКИ после
того, как домен направлен на хостинг (шаг 6). Загружать ничего не
нужно. Проверить: Панель хостинга → «Сайты» → pcm2.ru →
«SSL и антивирус» → сертификат установлен, HTTPS включён.
Если через сутки после шага 6 замка нет — тикет в поддержку:
«выпустите и установите сертификат из комплекта тарифа на pcm2.ru».

Путь А2 — купить сертификат у Руцентра
--------------------------------------
Если в тарифе SSL нет: Личный кабинет → «Заказать услугу» →
«SSL-сертификаты» → самый простой DV-сертификат на 1 год для
домена pcm2.ru (скидка SSL 10% из вашего пакета). Подтверждение —
по e-mail из данных домена или по DNS-записи (кабинет сам добавит
запись, если домен на DNS Руцентра). Купленный у Руцентра сертификат
на его же хостинг ставится автоматически.

Путь Б (бесплатно, но раз в 3 месяца руками)
--------------------------------------------
Выпустить Let's Encrypt самостоятельно (сервисы вроде ZeroSSL или
certbot на своём компьютере с подтверждением через TXT-запись
_acme-challenge в DNS), скачать три файла (сертификат, приватный
ключ, цепочка), затем Панель → «Сайты» → pcm2.ru → «SSL и антивирус»
→ «Установить» → вставить содержимое файлов. Через 90 дней —
повторить. Для тестового сайта это лишняя рутина.

Если панель при установке попросит выделенный IP-адрес — заказать
его в карточке услуги «Хостинг» (небольшая доплата к тарифу).

Включить редирект на HTTPS — ТОЛЬКО когда https://pcm2.ru уже
открывается с замком. В файле .htaccess (на хостинге, через
FileZilla → правой кнопкой → «Просмотр/Правка») убрать «# » в
начале двух строк под «# HTTPS»:
  RewriteCond %{HTTPS} !=on
  RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [R=301,L]
Сохранить, FileZilla спросит «Загрузить обратно на сервер?» — Да.

ШАГ 6. НАПРАВИТЬ ДОМЕН pcm2.ru НА ХОСТИНГ
===================================================================
Это единственный шаг, где мы трогаем раздел «Домены». Работаем
ТОЛЬКО в строке pcm2.ru.

6.1. Личный кабинет → «Домены» (Активные услуги → Домены).
6.2. Найти строку pcm2.ru. В колонке DNS сейчас statuspage1.nic.ru /
     statuspage2.nic.ru — это заглушка «сайт скоро откроется».
6.3. В этой строке нажать «Изменить» (под списком DNS-серверов).
6.4. В блоке «Использовать DNS-серверы услуг Руцентра» выбрать
     «Хостинг» → «Сохранить изменения».
     (Если такого переключателя нет — вписать вручную DNS-серверы,
     которые панель хостинга показывает в «Информации о хостинге»;
     у Руцентра это ns3-l2.nic.ru, ns4-l2.nic.ru, ns8-l2.nic.ru,
     ns4-cloud.nic.ru, ns8-cloud.nic.ru.)
6.5. Перед сохранением ещё раз глазами: в заголовке формы — pcm2.ru.
     Строку pc-moscow.ru не открываем и не меняем.

Ожидание: обычно 1–2 часа, официально до 24 часов. Проверка:
удалить строку из hosts (4.2), закрыть браузер, открыть
http://pcm2.ru — открывается наш сайт, а не заглушка Руцентра.
Также можно проверить с телефона через мобильный интернет.

Если сертификат (шаг 5, путь А) заказывали до этого шага —
подтверждение по DNS пройдёт только после 6.4.

ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
===================================================================
  Ошибка 500 сразу после заливки
      → в .htaccess закомментировать первую строку после заголовка:
        # Options -MultiViews -Indexes
        (некоторые хостинги запрещают эту директиву). Если не помогло —
        версия PHP ниже 7.4 (2.4).
  Главная открывается, разделы — 404
      → не залился .htaccess (3.4) или выключен mod_rewrite
        (написать в поддержку Руцентра: «включите mod_rewrite для
        сайта pcm2.ru»).
  Админка: «не удалось сохранить»
      → права на data/ (3.3).
  Картинки не грузятся
      → папка images/ залилась не полностью — перезалить,
        FileZilla → «Неудавшиеся передачи».
  pcm2.ru показывает заглушку Руцентра спустя сутки
      → DNS не переключился: Домены → pcm2.ru → проверить, что
        DNS-серверы уже не statuspage*.nic.ru.
  Заявки не приходят
      → SMTP: хостинг может блокировать исходящий порт 465 —
        спросить поддержку или поменять в inc/config.php на
        $SMTP_PORT = 587; $SMTP_SECURE = 'tls';
  Всё сломалось и нужно откатиться
      → ничего не делать с pc-moscow.ru. uitop.ru на Timeweb
        продолжает работать. pcm2.ru можно вернуть на заглушку
        (Домены → pcm2.ru → DNS → выбрать заглушку/парковку).
