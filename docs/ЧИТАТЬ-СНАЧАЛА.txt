ПЕРЕНОС САЙТА: TIMEWEB (uitop.ru) → NIC.RU (pcm2.ru)
====================================================
Версия от 16.09.2026

ГЛАВНОЕ ПРАВИЛО
---------------
Всё делается ТОЛЬКО с доменом pcm2.ru. Строку pc-moscow.ru в разделе
«Домены», его DNS-серверы, зону DNS-хостинга и папку с его файлами
НЕ ТРОГАЕМ. Новый сайт живёт в отдельной папке под отдельным доменом.
uitop.ru на Timeweb продолжает работать, пока pcm2.ru не проверен.


ШАГ 0. ЗАБРАТЬ СВЕЖИЙ КОНТЕНТ С uitop.ru
---------------------------------------
Всё, что правили через админку на uitop.ru (слайды, новости, команда,
каталог), лежит в data/*.json НА СЕРВЕРЕ Timeweb — в этом архиве
версия может быть старее. Перед заливкой:

  https://uitop.ru/backup.php?key=porsche

Скачается pcm-backup-….zip. Распакуйте и замените этими файлами
содержимое папки data/ в этом архиве. Если backup.php не отвечает —
скачайте папку data/ с Timeweb по FTP/SFTP из /var/www/mysite/data/.

Каталог cars.json можно не переносить — после заливки он обновится
импортом (шаг 6).


ШАГ 1. ПОДКЛЮЧИТЬ pcm2.ru К ХОСТИНГУ NIC.RU
-------------------------------------------
Личный кабинет nic.ru → Активные услуги → Хостинг → панель хостинга →
«Сайты» (или «Домены») → «Добавить сайт» → pcm2.ru.
Хостинг создаст отдельную папку вида /home/ЛОГИН/pcm2.ru/docs/
Запомните её — туда заливаем файлы.

Если в списке сайтов хостинга уже есть pc-moscow.ru — надёжнее заказать
для pcm2.ru отдельный самый дешёвый тариф хостинга: свой FTP, своя
версия PHP, свой cron, ноль общего с основным сайтом.

Хостинг должен уметь: PHP 8.x, .htaccess (mod_rewrite), cron,
исходящие соединения (для фидов MaxPoster и SMTP). У nic.ru это есть.
Версию PHP выставить 8.x ДЛЯ САЙТА pcm2.ru, глобальные настройки
хостинга не трогать.


ШАГ 2. ЗАЛИТЬ ФАЙЛЫ
-------------------
Содержимое этой папки — в /home/ЛОГИН/pcm2.ru/docs/ (корень сайта pcm2.ru),
с сохранением структуры:

  index.php, admin.html, robots.txt, sitemap.php, .htaccess, support.js,
  backup.php, import-cars.php
  assets/  inc/  pages/  data/  images/  api/  tractors/

inc/config.php ВКЛЮЧЁН и уже настроен на pcm2.ru:
  $SITE_URL       = https://pcm2.ru       (canonical, sitemap, og:url)
  $NOINDEX        = true                  (сайт закрыт от поисковиков)
  $ADMIN_PASSWORD = porsche               (как на uitop.ru)
  $ADMIN_TOKEN    = новый
  SMTP            = тот же ящик, что на uitop.ru

Файл .htaccess начинается с точки — в некоторых FTP-клиентах скрыт,
включите показ скрытых файлов и убедитесь, что он залился.

Папке data/ — права 775 (Permissions в FTP-клиенте).

На Timeweb сайт работал под nginx (конфиг «mysite»). На nic.ru — Apache,
маршруты берёт .htaccess. Конфиг nginx туда не нужен.


ШАГ 3. ПРОВЕРИТЬ ДО ПЕРЕКЛЮЧЕНИЯ DNS
-----------------------------------
Хостинг даёт временный адрес сайта (в панели, рядом с сайтом) — откройте
через него главную, /cars/, /news/, /admin/. Если временного адреса нет —
пропустите шаг, проверим после DNS.


ШАГ 4. НАПРАВИТЬ ДОМЕН pcm2.ru НА ХОСТИНГ
-----------------------------------------
Личный кабинет → Домены → строка pcm2.ru → в колонке DNS «Изменить» →
вписать DNS-серверы хостинга (панель хостинга покажет какие именно,
для nic.ru обычно ns3-l2.nic.ru / ns4-l2.nic.ru / ns8-l2.nic.ru).
Сейчас там statuspage1.nic.ru — это заглушка.

Меняем ТОЛЬКО строку pcm2.ru. Строку pc-moscow.ru не открываем.
Обновление DNS — от 15 минут до суток, обычно 1–2 часа.


ШАГ 5. HTTPS
------------
Панель хостинга → SSL-сертификаты → бесплатный Let's Encrypt для pcm2.ru.
Когда https://pcm2.ru откроется с замком — в .htaccess раскомментировать
две строки после «# HTTPS»:
  RewriteCond %{HTTPS} !=on
  RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [R=301,L]


ШАГ 6. АВТООБНОВЛЕНИЕ КАТАЛОГА
------------------------------
Сразу после заливки — вручную: https://pcm2.ru/import-cars.php?key=porsche
Потом панель хостинга → Cron (Планировщик) → задание раз в час:
  php /home/ЛОГИН/pcm2.ru/docs/import-cars.php


ПРОВЕРИТЬ ПОСЛЕ ЗАЛИВКИ
-----------------------
  https://pcm2.ru/              главная, в коде страницы canonical = pcm2.ru
  https://pcm2.ru/cars/         каталог
  https://pcm2.ru/news/         карточка «Тракторы Porsche» → /tractors/
  https://pcm2.ru/admin/        админка, пароль porsche, правки сохраняются
  https://pcm2.ru/robots.txt    Disallow: /
  https://pcm2.ru/sitemap.xml   адреса начинаются с https://pcm2.ru
  форма «Обратный звонок»       письмо пришло на info@pc-moscow.ru
  https://pc-moscow.ru/         ОСНОВНОЙ САЙТ РАБОТАЕТ КАК РАНЬШЕ


ШАГ 7. ЧТО ДЕЛАТЬ С uitop.ru НА TIMEWEB
---------------------------------------
Когда pcm2.ru проверен — на Timeweb ничего не удаляйте сразу:
1. Правки контента делайте только в админке pcm2.ru (иначе разъедутся).
2. Через неделю-две, если всё стабильно, — сайт на Timeweb можно
   выключить или оставить как резерв.


ЗАЧЕМ САЙТ ЗАКРЫТ ОТ ИНДЕКСАЦИИ
-------------------------------
pcm2.ru — копия контента pc-moscow.ru. Если поисковики увидят два
одинаковых сайта, они могут понизить основной. Пока pcm2.ru не станет
главным адресом — $NOINDEX = true и Disallow: / не снимать.


ЕСЛИ ЧТО-ТО НЕ ОТКРЫВАЕТСЯ
--------------------------
  Ошибка 500 / белый экран       → версия PHP ниже 7.4 или не залился .htaccess
  Открывается только главная     → на хостинге выключен mod_rewrite
                                   (написать в поддержку nic.ru)
  Админка не сохраняет           → права на data/ (775)
  Заявки не приходят             → проверить $SMTP_* в inc/config.php
