ДИЗАЙН V3 «СТУДИЯ» — КАК УСТАНОВИТЬ
====================================

Что в архиве (пути — относительно корня сайта /home/pcm7937440/pcm2.ru/docs/):

  assets/style3.css   — новая тема для ВСЕГО сайта (все классы прежние, меняется только вид)
  assets/site.js      — карусель главного экрана (раньше скрипт был внутри home.php)
  inc/head.php        — шрифт Exo 2 вместо Manrope/Tilda, подключение style3.css и theme.php
  inc/theme.php       — новый файл: заглушки-силуэты для машин без фото, ярлыки «Новый / Электро / Гибрид»
  inc/header.php      — тёмная шапка: верхняя полоса с адресом, меню, телефон, кнопка «Обратный звонок»
  inc/footer.php      — новый подвал; форма обратной связи прежняя
  pages/home.php      — главная: студия-карусель, авто в наличии (5 + плитка «весь каталог»), сервис, новости

ПОРЯДОК
1. Сделайте резервную копию папок inc/, pages/ и assets/ (или запустите backup.php).
2. Залейте файлы архива поверх сайта по FTP. Старые style.css / style2.css можно не удалять.
3. Откройте главную с Ctrl+F5. Проверьте: меню на телефоне, свайп карусели, кнопку «Обратный звонок» в шапке.

ЧТО ПРОВЕРИТЬ / НАСТРОИТЬ
- Слайд с автомобилем без фона (как в эскизе «Студия»): в data/slides.json у слайда добавьте
    "cutout": true
  и укажите PNG с прозрачным фоном шириной от 1600 px (images/911-carrera.png — всего 640 px, для главного экрана мал).
  Слайды с обычными фото автоматически показываются «в студии»: фото справа с плавным уходом в тёмный фон.
- Фильтры над каталогом на главной («Cayenne · Macan · Taycan · Другие марки») строятся из поля line в cars.json.
- Кнопка «Обратный звонок» в шапке открывает уже существующее окно виджета; плавающая кнопка внизу теперь
  показывается только на экранах уже 1040 px.
- Короткий адрес в верхней полосе задан прямо в inc/header.php (строка «Москва, Ленинградское шоссе, 71А»).

ШРИФТ
Сайт грузит Exo 2 с Google Fonts. Для скорости скачайте семейство (лицензия SIL OFL, бесплатно) —
https://fonts.google.com/specimen/Exo+2 — положите woff2 в assets/fonts/, раскомментируйте блок @font-face
в начале style3.css и удалите три строки <link> Google Fonts из inc/head.php.

ОТКАТ
Вернуть старые inc/head.php, inc/header.php, inc/footer.php, pages/home.php из резервной копии — тема отключится.
