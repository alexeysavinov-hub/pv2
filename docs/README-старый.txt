# PCM — многостраничный сайт для FTP-хостинга (reg.ru)

Это НЕ одностраничник. У каждого раздела свой настоящий адрес, контент
подставляется на сервере — поисковые роботы видят готовый HTML.

## 1. Загрузка
Загрузите СОДЕРЖИМОЕ этой папки (не саму папку) в корень сайта — обычно
public_html/. Должно получиться так:

    public_html/
    ├── .htaccess
    ├── index.php
    ├── admin.html         ← админ-панель, открывается по /admin/
    ├── support.js
    ├── robots.txt
    ├── sitemap.php
    ├── api/
    ├── assets/
    ├── inc/
    ├── pages/
    ├── data/
    └── images/

Требования хостинга: PHP 7.4 или новее и включённый mod_rewrite
(на reg.ru есть по умолчанию).

## 2. Настройка (обязательно)
Откройте inc/config.php и укажите:

    $SITE_URL        адрес сайта без слэша на конце, например
                     https://pc-moscow.ru — используется в canonical
                     и sitemap. Если оставить чужой домен, поисковики
                     склеят страницы не туда.
    $SITE_EMAIL      куда приходят заявки с форм
    $ADMIN_PASSWORD  пароль входа в админку
    $ADMIN_TOKEN     любая длинная случайная строка

Затем откройте robots.txt и замените домен в строке Sitemap.

Проверьте, что открываются:
    /                 главная
    /cars/            каталог
    /news/            новости
    /admin/           админ-панель
    /sitemap.xml      карта сайта

## 3. Чтобы правки из админки попадали на сайт
По умолчанию $USE_DB = false — авто, слайдер и новости читаются из файлов
в папке data/. Сайт работает сразу, но правки из админ-панели остаются
в браузере редактора и посетители их не видят.

Чтобы правки были видны всем и попадали в HTML для роботов:
 1. Создайте базу MySQL в панели хостинга.
 2. В inc/config.php поставьте $USE_DB = true и впишите $DB_HOST,
    $DB_NAME, $DB_USER, $DB_PASS.
 3. Откройте /admin/, войдите по паролю и сохраните любую запись —
    данные уйдут в базу, и страницы начнут отдавать их роботу.

Таблица pcm_store создаётся автоматически при первом обращении.
Файлы в data/ остаются стартовым набором: если в базе ещё ничего нет,
сайт показывает их.

## 4. Заявки с форм
Формы отправляются на сервер и уходят письмом на $SITE_EMAIL.
Копия каждой заявки дополнительно пишется в data/leads.log — на случай,
если почта на хостинге не настроена. Проверьте этот файл после первой
тестовой отправки.

Если письма не приходят, на reg.ru нужно создать почтовый ящик на домене
и включить отправку через mail() — либо подключить SMTP.

## 5. Адреса разделов
    /                        главная
    /cars/                   каталог автомобилей
    /cars/cayenne/           фильтр по модельному ряду
    /cars/<модель-год-id>/   карточка автомобиля
    /models/                 модельный ряд
    /models/911/             версии модели и наличие
    /service/                сервис
    /service/parts/          запасные части
    /service/body/           кузовной ремонт
    /service/poa/            доверенность
    /service/offers/         спецпредложения
    /service/offers/<слаг>/  страница предложения
    /finance/                кредит, лизинг, страхование
    /news/                   новости
    /news/<слаг>/            публикация
    /about/                  о компании
    /about/team/sales/       отдел
    /contacts/               контакты
    /legal/pdn/              правовые документы
    /admin/                  админ-панель (закрыта от индексации)

## 6. После запуска
 - Добавьте сайт в Яндекс.Вебмастер и Google Search Console, укажите
   там /sitemap.xml.
 - Установите SSL-сертификат, затем раскомментируйте редирект на HTTPS
   в .htaccess.
 - Там же раскомментируйте склейку www / без-www — выберите один вариант.
 - Смените $ADMIN_PASSWORD и $ADMIN_TOKEN на свои.

## 7. Что стоит доделать
 - Фото модели 718 сейчас берётся от 911 (data/models.json) — замените
   на своё изображение.
 - Часть фотографий сотрудников отделов продаж и сервиса подгружается
   по ссылкам с pc-moscow.ru. Лучше скачать их и положить в images/,
   поправив пути в data/team.json.
 - Изображения весят по 1–2 МБ. Для скорости загрузки их стоит сжать
   и перевести в WebP.

## Спецпредложения сервиса (новое)
В админке появилась вкладка «Спецпредложения сервиса». Карточки из неё
показываются на /service/offers/ и на страницах /service/offers/<слаг>/.
Данные: таблица pcm_store (name = 'offers'), стартовый набор — data/offers.json,
API: GET/PUT /api/offers. Пока раздел пуст, страница показывает слайды карусели.

## Наша команда (новое)
Вкладка «Наша команда» в админке: отделы (Руководство, Продажи, Сервис,
Клиенты), внутри — сотрудники: фото, имя, должность, телефон, e-mail,
порядок ▲▼. Данные: pcm_store (name = 'team'), стартовый набор — data/team.json,
API: GET/PUT /api/team. Показывается на /about/ и /about/team/<отдел>/.
